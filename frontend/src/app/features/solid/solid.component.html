Les principes SOLID

Cinq principes de conception orientée objet — un par lettre de l'acronyme — pour écrire du code plus simple à comprendre, à tester et à faire évoluer.

SOLID n'est pas un dogme : c'est une boussole pour limiter le coût du changement.

Popularisés par Robert C. Martin, ces cinq principes guident la façon dont on découpe les responsabilités et organise les dépendances. Choisissez un principe ci-dessous pour le découvrir en détail : définition, problème résolu, exemples de code à éviter puis à préférer, et comment l'appliquer.
